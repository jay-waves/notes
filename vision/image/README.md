**色调 (Hue)**: 描述颜色的种类或名称, 色轮中色调被表示为0~360度之间的角度.

**饱和度 (Saturation)**: 描述色彩纯度 (是否被灰色稀释), 0%饱和度意味着全灰色. 如鲜红色的饱和度高于浅粉红色.

### 亮度、对比度、深度

**亮度**: 0~255 表示灰度图像的亮度。不过最终呈现的亮度由显示设备和环境光决定。

**对比度**: 图像较暗部分和较亮部分的亮度差异

**深度**: 物体远近, 光的反射速度

### 数字图像的表示

数字图像是离散化存储的，可视为 $m\times n$ 像素矩阵。对于每个像素：

* 色深：指一个像素的某个色彩通道所用的数据量，如 8b / 10b / 12b 色深
* 灰度图像：亮度色阶，一般用 8b 表示
* 彩色图像：RGBA 色阶，一般用 4*8b 表示

## 数字图像处理

借鉴了很多[信号与系统](../../robo/cybernetics/README.md)的设计，在图像数字化时，

* 采样，指连续图像被表示为离散的像素点矩阵
* 量化，指单个像素点的灰度值或色度值的离散化，量化层次越多，色彩表示约细腻

## 图像处理

图像处理一般有两个目的：增强，让图片更清晰、更易观察；复原，让受损
的图像更接近真实原始图像。

图像的质量、易懂 (Intelligiblity)、保真 (Fidelity) 都是偏主观的概念，对不同的图像处理
任务，有不同的衡量标准。
