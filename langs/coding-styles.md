
- C 代码使用 Linux Kernel 风格
- Go 代码使用 Google 风格.
- C++ 代码使用标准库风格, 即全小写.
- Python 使用 pep8-style 风格.
- 不要求控制行长度, 建议代码行长度不超过 100 字符, 全角占两字符.

> Don't Repeat Yourself
> 
> Keep it simple and stupid

1. 函数不要超过 20 行，注意代码可读性、简洁性。
2. 避免过深的缩进
3. 简化控制语句的嵌套与复用，功能单一而分离
4. 变量名的长度，和变量名对程序的影响范围正相关
5. 按改动频率、代码热点来拆分代码结构和优化性能。不要一开始就过度设计。
6. 数据默认**不可变** (const)，函数默认是纯函数。
7. 移除全局共享的数据。
8. 变量初始化和变量声明写在一起。
9. 对于核心和数据结构，提供完整的测试集。其他交给集成测试。
10. 减少注释和文档记录细节，代码说明细节
11. 减少不必要的临时变量（状态），减轻阅读记忆负担
