
熵编码为什么不能取代游程编码、字典编码？

> 熵编码只能在已有的符号模型下做到边际熵最小，但是无法做到“条件熵”最小。
> 假设原文 ABABABAB
> 熵编码（单字符编码）: 01010101；
> 熵编码（双字符编码）：0000；
> 游程编码：4AB；
> 
> 以 DEFLATE 算法为例，先用 LZ77 将重复字符串编码为紧凑符号，然后用 Huffman 压缩
> 进行符号的熵编码。

## RLE (Run Length)

A string: `RRRRRGGGBBBBBRRRRGB` 

RLE: `5R3G5B4R1G1B`

## FSST (Fast Static Symbol Table)

用于消除字符串的子串重复

`Eastwood  Eastman  Easton` --> `[E]wood  [E]man  [E]on` 

## LZ77

LZ77 也类似字典压缩，为重复出现的字符串建立字典，而不重复存储。
* look-ahead-buffer (lab): a fixed number of symbols, to be coded
* search-buffer (sb): a fixed number of symbols from the past
LZ77 用滑动窗口、索引表来查找文本中最长匹配。

```
ABCABCABCABC

lz77:
(A,0)
(B,0)
(C,0)
(3,9,EOF)  --> 指向前回溯 3 个字符，并复制九个字符
```
